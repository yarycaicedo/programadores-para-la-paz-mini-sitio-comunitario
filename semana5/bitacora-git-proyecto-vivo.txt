1. Nombre del repositorio único de Semana 5:
Respuesta: programadores-para-la-paz-mini-sitio-comunitario

2. ¿Qué rama actualizan los docentes?
Respuesta: La rama main es la que actualizan los docentes con mejoras y cambios nuevos del proyecto base.

3. ¿Qué rama usa cada estudiante para trabajar?
Respuesta: Cada estudiante trabaja en su rama personal con formato nombres_apellidos, en mi caso yary_caicedo.

4. Comando usado para clonar el repositorio:
Respuesta: git clone https://github.com/yarycaicedo/programadores-para-la-paz-mini-sitio-comunitario.git

5. Comando usado para entrar a la carpeta del proyecto:
Respuesta: cd programadores-para-la-paz-mini-sitio-comunitario

6. Comando usado para crear tu rama personal:
Respuesta: git checkout -b yary_caicedo

7. Comando usado para verificar la rama actual:
Respuesta: git branch

8. Comando que se usará desde la Clase 22 para traer cambios de main:
Respuesta: git pull origin main

9. Explica con tus palabras qué significa fast-forward:
Respuesta: Fast-forward significa que Git pudo traer los cambios nuevos de main a mi rama sin conflictos, porque yo no había modificado las mismas partes que los docentes. La actualización fue limpia y directa.

10. ¿Por qué no se debe trabajar directamente en main?
Respuesta: Porque main es la rama base que actualizan los docentes y si trabajo directamente ahí puedo generar conflictos o perder los cambios del proyecto base. Cada estudiante debe trabajar en su propia rama personal.

11. Comando usado para revisar cambios al final:
Respuesta: git status

12. Comando usado para agregar cambios:
Respuesta: git add .

13. Comando usado para crear commit:
Respuesta: git commit -m "Clase 21 inicio proyecto unico mini sitio"

14. Comando usado para publicar tu rama:
Respuesta: git push -u origin yary_caicedo
