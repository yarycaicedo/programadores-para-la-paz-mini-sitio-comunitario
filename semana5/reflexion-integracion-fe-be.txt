Escribe una reflexión de 8 a 10 líneas respondiendo:

¿Por qué conectar el frontend con el backend ayuda a que un mini-sitio comunitario mantenga información dinámica, actualizable y útil para la comunidad?

En tu respuesta menciona al menos cinco de estas ideas:

- integración Frontend-Backend
- consumo de la API propia
- mensajes dinámicos
- frontend
- backend
- API
- JSON
- fetch
- async
- await
- render dinámico
- comunicación responsable
- revisión de fuentes
- consistencia comunicativa
- moderación editorial básica
- participación ciudadana
- cultura de paz

Respuesta: la integración Frontend-Backend permite que un mini-sitio comunitario muestre información actualizada sin necesidad de modificar manualmente el contenido del frontend. Gracias al consumo de la API propia, el frontend puede consultar datos que el backend entrega en formato JSON. Para realizar esta comunicación se utilizan fetch, async y await, lo que permite obtener la información de manera organizada. Los mensajes dinámicos se cargan mediante render dinámico y aparecen automáticamente en el tablero. Esto facilita mantener información útil y actualizable para la comunidad. Además, fortalece la comunicación responsable porque los mensajes pueden revisarse antes de publicarse. La revisión de fuentes y la moderación editorial básica ayudan a garantizar la calidad de la información. También se mantiene la consistencia comunicativa entre los diferentes contenidos. Finalmente, esta integración favorece la participación ciudadana y promueve una cultura de paz mediante información clara, verificable y accesible.
